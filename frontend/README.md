# frontend/

**소유: Phase 1 — 프론트엔드 트랙**

이 디렉터리 전체를 프론트엔드 트랙이 단독 소유한다. Phase 0 에서는 자리만 만들어 두었다.

## 스택

React + TypeScript + Vite / Tailwind CSS / TanStack Query / Recharts.

## 화면 (설계 문서 "화면 구성")

- **대시보드** — 기간·정책 선택, 시간대별 오류 건수 차트(metric 쿼리 기반),
  서비스별 오류 건수, 상위 오류 그룹 테이블.
  분석 상태는 그룹 id 가 아니라 **fingerprint 기준**으로 표시한다.
- **분석 정책 관리** — Loki 연결 선택·연결 테스트, LogQL·기간·한도·제외 정규식,
  저장 전 실행 결과 미리보기.
- **LLM 연결 관리** — 프로바이더·모델, API 키 입력(저장 후 마스킹 표시),
  base URL, 연결 테스트, 기본 연결 지정.
- **오류 그룹 상세** — 요약·추이·라벨, 마스킹된 대표 로그, AI 분석 실행·진행 상태,
  결과(가설·근거·확인 순서·완화 조치·한계), Markdown 보고서 내보내기.
- **분석 이력·사용량** — 실행 목록과 성공/실패, 모델별 토큰·추정 비용·평균 응답 시간.

## API 계약

백엔드 라우터 시그니처와 Pydantic 모델이 계약이다. 다음 두 곳만 보면 된다.

- `backend/app/schemas/api.py` — 요청/응답 모델
- `backend/app/schemas/analysis.py` — LLM 분석 결과 스키마
- 라우트 목록은 `GET /openapi.json` 또는 `/docs` 로 확인 (백엔드 기동 후)

스키마 파일은 **동결(freeze)** 상태다. 변경이 필요하면 직접 고치지 말고 보고할 것.

## 표시 규칙 (계약상 제약)

- LLM 결과는 사실이 아니라 **원인 가설**로 표시하고, 항상 원본 로그로 돌아갈 링크를 붙인다.
- `severity` 는 "LLM 추정 심각도"로 표기하고 발생량 기반 지표와 분리해 보여준다.
- `confidence` 는 정렬용 힌트일 뿐 확률로 표기하지 않는다.
- 비용은 항상 "추정" 표기를 유지한다.
- 기간·라인 수 상한은 서버가 강제한다. UI 제한은 편의일 뿐 신뢰 대상이 아니다.
